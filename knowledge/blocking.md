# Blocking

Blocking is a causal timeline. Give each meaningful beat a start, end, actor, primitive, and optional target. Use explicit anticipation, action, transition, and settle periods for rises, falls, turns, and movement. Keep held characters in the same plan so they remain part of the composition.

The V1 evaluator samples every frame, eases transitions, resolves target facing, and bakes linear Blender keys. A good block preserves foot contact, weight transfer, approach distance, and the order of initiative changes even when the proxy is minimal.
