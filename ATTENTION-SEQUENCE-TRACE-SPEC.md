# Attention Sequence Trace

`ATTENTION-SEQUENCE-TRACE/1.0` is diagnostic data, not a seventh AG object or an automatically lowered event. It records target, notice time, head response, body response, and ordering assertions. R2 records A noticing C at 3.5s and B noticing C at 4.25s; B's split primitive runs head 4.2667–5.2667s, body 5.4667–8.0s.
