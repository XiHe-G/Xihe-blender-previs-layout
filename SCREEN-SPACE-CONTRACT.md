# Screen-Space Contract / 1.0

World direction and screen direction are separate contracts. A direction is evaluated from projected centers using the same S3/S3.5 projection code. Supported labels are `LEFT_TO_RIGHT`, `RIGHT_TO_LEFT`, `UP`, `DOWN`, `TOWARD_CENTER`, `AWAY_FROM_CENTER`, and `HOLD_REGION`, each with a minimum displacement and camera reference. R2 corrected five historical technical labels because the original source shot intent was unspecified.
