# 导演制作流程 · 1.8.1

目标是从剧情或文字分镜开始，完成可读的连续 Layout；参考视频只用于可选研究或还原，不是必需输入。Codex 负责解释文字、导演设计和看画面，Python 合同负责执行明确决策和检查不变量，两者不能混称“自动理解剧情”。

## 先判断任务与权限

先选择 DESIGN_FROM_STORY、EXECUTE_CONFIRMED_STORYBOARD、REVISE_EXISTING_LAYOUT 或 OUTPUT_PACKAGE。整理用户本轮要求、已确认分镜、剧本、工程和历史反馈的字段来源；最新明确修改只覆盖对应字段。剧本补充因果，不悄悄覆盖已确认摄影。不要把候选时长写成已批准时长。执行前检查 Blender 版本、外部资产、相对路径、依赖和输出权限，记录源哈希。

用户授权自主创作时，未锁定的常规机位、构图、节奏和调度可以先做具体候选；只有改变锁定内容、重大剧情歧义或超出权限才问。既有“先看路线图再做”的要求仍按项目执行。AUTONOMOUS_CANDIDATE 是授权做候选，绝不是用户已批准具体设计。不要重复询问已明确的指令；也不要根据沉默伪造批准。

## 从文字到可拍方案

1. 阅读场前、场内和场后，标清现实／回忆／梦境等时间层。记录每个角色此刻想做什么、知道什么、结果改变什么；不要把后来终点提前搬到开场。
2. 把故事写成可见的信息节点：观众先看什么，谁察觉／行动，谁反应，造成什么后果。对白不是全部动作；保留倾听、停顿和视线承接。时长根据对白试读、可读动作和反应分配，不平均分镜，不套固定每镜秒数。
   明确这场戏跟随谁的经验、观众与人物的信息差和关键转折。用空间／调度／摄影承载可见变化；只在有真实取舍时比较同框调度、切镜和运镜。参考的具体借用维度及选择理由见 [摄影决策方法](cinematography-for-layout.md)，可直接记入现有计划，不必另填表。
3. 先解决共同空间：入口、出口、支撑面、主轴、角色真实身高与眼高、道具归属。每人都有起点、朝向、行动节点、终点和镜外状态；群体不能只写一条路线。世界居中与画面居中分开处理。
4. 每镜明确 purpose / first_focus / start_read / end_read / cut_reason；明确主体、景别、机位相对眼或肩的位置、镜头感光面、焦距、运动形式、关键事件和可读结果。静止镜头是合法选择。无剧情收益的绕行、逐人寻找和额外摇移应去掉。
   先决定观众与主体的距离和背景关系，再结合画幅、感光面、焦距实现截幅；需要前后景同时读懂时不要默认虚化。焦点转移、变焦等未由当前适配器支持的意图，必须交给可支持的显式执行路径，或标明尚未实现。
5. 摄影路径、朝向、焦距、时间曲线分开设计。下一镜用 Camera Cut；镜内连续移动只有分镜或叙事需要才做。原分镜本身包含冲突的复杂运动时，保留忠实候选并说明冲突，另做已授权的导演备选，不能偷偷替换。
6. 在同一个场景状态和时间轴执行。用粗模和少量关键节点先验证极值位置、遮挡、接触和起落幅，再补中间过程。环境只搭到能表达空间、视差、支撑、光向的程度；要求简场时不添加后景和装饰特效。

DIRECTOR_PLAN/1 的字段检查只验证上述决定存在且数值可执行，不能验证决定正确。参见 [执行接口](local-upgrade-runtime.md)。

## 文戏、运动戏的不同重点

文戏关注说话者与反应者、视线目标、倾听停顿、道具持握、转身前后脸与反应是否看得见。单人近景有背景角色时，先检查站位关系与视锥；不能无授权隐藏演员，也不能无限变焦追求指标。

打戏沿用现有 ACTION_BEAT、AG/CSP 与接触门禁。每个攻防节拍写清主动方、威胁方向、察觉窗口、应对路径、接触或险过、受力结果、恢复与下一拍条件。动作不能为了镜头重新瞬移。穿越、躲避与落地检查实际身体／道具轮廓和整个支撑范围，不能只测 root 或 COM。稳定接触点身份与最近点切换要区分。没有手部／脚部代理就不能声称验证了手脚接触；关键交互需要对应代理和局部验证，精细 IK／步态仍按能力表标记限制。

## 审片与沟通

镜表和审阅视频按 [可适配规范](adaptive-layout-review.md) 组织：保留可执行语义、完整镜头画幅、同步的描述／对白与可定位的反馈，列数和排版随项目调整。制作规范中的示例角色和格式不自动成为所有项目的要求。

先完整 1× 看真实编码视频，再按事件窗口、起落幅和切点证据归因。若工具只能抽帧，写明 PLAYBACK_NOT_REVIEWED，不能说已完整观看。技术指标只能支持具体问题；主观表演、情绪和摄影效果独立记录。

默认汇报已完成成果、最重要的问题和下一步。例行机位修正不逐镜请示；关键冲突一次集中提问，给具体候选及后果。交付链接先于长报告；只要三镜就交三镜，已渲染且仍有效的镜头复用。制作结束后停止，等待实际审片。
