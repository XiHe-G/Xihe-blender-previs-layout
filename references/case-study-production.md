# 匿名制作案例：空间、调度与状态连续

本页只保留可迁移经验，不包含原项目人物、镜号、路径、会话或素材。它不是可重放的生产基准。

- 场景标注、当前分镜与旧版资料分别记录权威范围。可见性检查不能证明地点认对；先核对地标、坡度、入口、出口和遮挡。
- 群体调度先写共同起点、分组节点、镜外等待和离开终点。不得用隐藏对象代替连续退场，也不得把未来站位提前到开场。
- 相对身高与场景米数分开记录；估算比例不能冒充官方设定。默认五件／四件 Box 模型保持简化，按接触动作增设临时代理。
- 道具交接、投出、冻结、反向与命中保持同一对象和清楚的所有权；角色阻拦与被阻拦反应按因果错开。
- 相同通道被休息姿态与动作逻辑重复写入会产生闪跳。修正负责窗口内的键、重烘焙并核对四元数半球；根控制器稳定不代表局部代理稳定。
- 正常速度视频、镜前镜后状态和保存重开的原生轨迹分别核验。联系表不能代替整段观看；技术检查不能代替导演批准。

用通用时间编译、已有场景渲染和媒体检查工具支持制作。专用剧情表演仍由项目适配器显式实现，不能把一次项目成功宣称为通用动作能力。
