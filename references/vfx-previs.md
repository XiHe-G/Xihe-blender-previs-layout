# VFX previs

Status: INTERFACE_ONLY; typed schemas/validator only. Accepted old semantic proxy lifecycles remain available, but these new type profiles are not automatically lowered to them.

Describe when, where, source, propagation direction, size, duration, affected entities and result. Types: FIRE / SHIELD / EXPLOSION / ENERGY_BEAM / RIFT / LIGHTNING / AURA / WAVE / SMOKE. Time is an existing event reference. FIRE requires emitter, height, spread, direction, growth, flicker envelope, residue and light contribution reference; SHIELD requires volume, activation, hold, impact point, ripple and break/recover; EXPLOSION requires origin, expansion, peak radius, force direction, flash, debris direction and residue. Other types use emitter/propagation/envelope/residue scaffolding pending project training.

Keep SEMANTIC_EFFECT, VFX_VISIBLE_GEOMETRY and VFX_LIGHT_CONTRIBUTION independent. Visible fire does not prove illumination. A shield volume does not finalize material; expansion does not specify final smoke/fire. Enabled light contribution requires a separate lighting event reference and native validation; proxy presence never substitutes for it. No final VFX assets, shaders or physics are generated by this module.
