# Historical combat regressions

The original development release used frozen CDR fixtures and native geometry. These project assets and historical evidence archives are not distributed in this public source package. Do not run commands that assume they exist or claim their past PASS as a result of the public tests.

The reusable CSP builder and regression checker remain available for your own authorized fixtures. Supply a matching sequence, geometry, evaluated baseline and provenance. Rebuild to a new output location, reopen the saved scene, compare actual transforms and review normal-speed output. Preserve original failures and distinguish technical checks from director acceptance.

For included portable examples use `templates/action-expression-travel.json`, `templates/action-expression-impact.json` and `examples/director_workflow/`. See [distribution scope](../PUBLIC-DISTRIBUTION.md).
