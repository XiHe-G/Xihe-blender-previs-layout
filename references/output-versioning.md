# Output selection and version binding

Status: INTERFACE_ONLY production delivery automation; manifest/file-hash compiler implemented. Use existing render_existing and verify_delivery for native/render/media checks. The new compiler cannot prove that a video was rendered from a Blend by matching declared metadata alone.

Choose only requested combinations: IDENTITY_COLOR_LAYOUT / NEUTRAL_LIGHTING_LAYOUT / LIT_LAYOUT / VFX_FUNCTION_LAYOUT / ENVIRONMENT_HIDDEN_LAYOUT with CLEAN / DEBUG / DIRECTOR_REVIEW. Do not generate the entire matrix. Preserve established project defaults; for new projects without an output convention, use the recommendations in [adaptive review](adaptive-layout-review.md). DIRECTOR_REVIEW may be named REVIEW in filenames; keep the existing schema enum when using the delivery compiler. CLEAN retains action-bearing semantic proxies; DEBUG adds diagnostics, not a different animation. REVIEW preserves the complete shot picture and synchronized shot descriptions/dialogue, with layout, target size, fps and aspect ratio adapted to the project. Do not add a review-only intro that shifts its frame correspondence. Existing technical stills/contact sheets can remain in the delivery package; the new artifact list currently binds VIDEO variants only.

Every manifest binds project, scene, sequence, ordered shot range, source Blend, layout/lighting/visibility/camera versions, resolution, frame range and revision IDs. Each listed video carries the identical binding and file SHA; source Blend SHA is separately verified. Compiler rejects version drift, missing/extra variants, frame gaps, reordered camera tables, missing changelog revisions, missing files, path escape and wrong hashes.

`compile_delivery(manifest, package_root)` returns DELIVERY_MANIFEST, CHANGELOG, CAMERA_LIST, SHOT_RANGE and a limited EVIDENCE receipt. CLI writes this as one JSON package (`--output`, exclusive creation). Extract named sections if downstream requires separate files; retain their common manifest fingerprint. Do not overwrite older deliveries. Source/render receipts and verify_delivery establish actual freshness; compiler output explicitly reports native_render_provenance and visual_review NOT_REVIEWED.

Exporting a review or final package does not itself authorize a downstream handoff. Generate its card only after explicit user final approval and actual delivery of that same final layout; apply [downstream-handoff.md](downstream-handoff.md). Preserve normal output selection and legacy rendering behavior.

Partial 15-second or shot-range output uses its real frame range/cut list and source version, not a newly invented timeline. Hashes are integrity checks, not director acceptance. Mixed Blend A/movie B/camera table C is an error even when filenames look similar.
