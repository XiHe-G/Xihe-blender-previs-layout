# 从导演意图到可验证的 Layout 摄影

用于原创导演设计、摄影问题诊断和已有分镜的参数落实。吸收《导演的摄影课》的故事、视觉阐释、镜头、景深、参考、色调、运动及制作协作思想；具体页码与阅读边界见 [资料吸收记录](source-study-20261028.md)。以下是针对本 Skill 的方法转化，不是书中原文或电影摄影规则大全。

## 1. 把感觉翻译成观众能读到的变化

从场景前后的剧情出发，先说明：这场戏跟随谁的经验，他想要什么、知道什么，转折在哪里；观众与角色的信息何时一致、何时有意错开。情绪词要落到可见关系，例如“他失去控制”可以落实为被逼退、空间被占据、目光失去回应或下一步选择被封住。具体方案由当前故事决定，不预设一定使用仰拍、手持或特写。

新设计时可在既有计划里留一个简短的**视觉命题**：希望观众怎样体验场景，用哪些空间／摄影关系支持它，在哪个节拍改变。场景级先选一个基调，逐镜围绕它发展；转折允许变化，但别让每镜任意换一套视觉语言。已确认分镜只补足落实它所需的参数，不能借学习书籍重新导演。

例：A终于发现B在隐瞒，未必是“推近A”。若观众应先知道，可让B藏物的动作在后景短暂可读、A尚未察觉；若观众要与A同时发现，则控制遮挡或视线显露时间。若关系已通过同框动作清楚改变，固定镜头也能成立。这是可比较的设计推理，不是可套用的剧情或镜头模板。

## 2. 从空间关系设计镜头，而非按台词轮流切人

先排完整行动和倾听反应，再观察固定机位是否已经能传递转折。必要时比较同框调度、镜内注意力转移与切镜覆盖；选能保住关键表演和信息顺序的方案。不是每句台词都需要反打，也不是每场戏都需要大全景开场。让远近、前后、遮挡、目光和人物占据的空间承担关系变化。

分镜同时是在预演剪辑：起幅接收上镜留下的信息／动作，镜中产生变化，落幅为下一镜留下可读状态。镜头目的、信息增量、切入／切出理由记录在已有 purpose / first_focus / start_read / end_read / cut_reason 中，不另造一条时间线。镜内阶段不是自动拆镜理由。

覆盖按风险选择：关键发现、接触、反应或空间重建确实不能由当前画面承担时才补角度；别机械堆齐主镜头、正反打、特写。故事板／路线图可以是粗略但可执行的，复杂动作与精确遮挡值得更多预演；小范围改字或导出无需重走全套设计。书中允许灵活调整的思想只适用于未锁定或已授权的选择。

## 3. 机位、焦距、景别和画幅联合选择

先选观众与主体的空间关系，再用镜头参数实现构图。记录实际画幅、sensor fit／有效感光面、焦距、相机距主体及前后景关系；毫米数不自动对应景别或情绪。“广一些”“更亲近”“更有压迫”需要解释是截幅、距离、透视、遮挡还是表演关系出了问题。

| 叙事问题 | 候选手段 | 需要观察的代价／反例 |
|---|---|---|
| 环境与人物同样重要 | 给关键环境可读面积、纵深与清晰度 | 广角不能代替可读布局；远处动作可能过小 |
| 靠近人物体验 | 靠近机位配合合适视角，或在原机位收紧取景 | 近距离透视与侵入感、背景关系会变化；不能把两个方案当同义 |
| 保持旁观／窥视距离 | 远处机位配合较窄视角、遮挡或取景限制 | 这是候选语法，不意味着长焦一定是偷窥 |
| 表达权力／失衡 | 高低关系、占幅、前后层次、姿态与视线共同设计 | 仰拍不必然强大；坐姿、巨物或视点约定可能只是空间事实 |
| 多人关系需要同时比较 | 同框层次和可读窗口，必要时调整机位／焦点 | 不为塞进所有人而破坏关键反应；有意隐藏者可在镜外 |

**透视与视差主要由观察位置决定。** 同一机位只改焦距，主要改变视角／取景范围；为保持人物同样大小而同时改变距离和焦距，才会明显改变人物与背景的比例关系。推轨会改变观察位置和视差，变焦不产生同样的位移。不要将书中口语化的“长焦压缩”“推轨保持景深”直接写成无条件物理规则。景深还依赖焦距、光圈、对焦距离、画幅和可接受清晰度；推轨时也可能需要跟焦。

如需数值核查，普通无畸变透视模型可用 `视角 = 2 atan(对应有效感光面尺寸 / (2 × 焦距))` 作交叉检查，并以 Blender 实际投影为准。不要照搬“50mm是人眼”“标准镜头约180°”或历史器材的画幅分类。非透视／变形投影和镜头畸变需其明确模型；不因选择宽画幅就声称实现了变形镜头。

## 4. 把焦点当作信息分配，而非默认背景虚化

先判断观众需不需要同时读前景与后景。需要读威胁、关系或环境因果时保留相应清晰度；要孤立某个人或让观众延迟发现信息时，可以采用浅景深、遮挡或镜头选择。焦点转移与“头朝向哪里”不同：它决定观众何时能清楚地看见另一个对象。

需要焦点变化的镜头，在已有备注中说明起点目标、转移触发、到达目标与阅读窗口；由当前可用执行器显式实现。若实现尚不支持，则保留为未执行意图并报告，不塞入未支持字段假装生效。新 DIRECTOR_PLAN 相机适配器仍只支持每镜固定焦距，未新增自动跟焦、景深或变焦执行能力。

正反打检查景别、机位距离、背景尺度和清晰度能否形成预期关系；可以为权力差、主观性或不安有意不对称，不强制相同焦距。所有选择都要在真实动作范围内检查：走近、坐起、递物、转头时主体是否仍可读。普通白盒默认清楚呈现动作；不要用虚焦遮盖失效的 Layout。

## 5. 运动服务信息与情绪，停住也有意义

选择运动时区分功能目的（跟随、重构图、揭示空间）和心理目的（靠近体验、等待、疏离、失衡），可兼有。主观体验不等于必须手持；静止也不保证客观。具体视点由镜头所处的叙事关系决定。

先比较镜头固定、人物调度、切镜及移动机位中哪些足以完成目的；无需为每个简单镜头提交多个方案。确有权衡时做最小对照，只改影响判断的变量，保留批准版本。

运动要有“何时开始、为何开始、跟随／揭示谁、何时停、落幅需要读到什么”。可以提前引导、同步跟随或稍后追上，但不能因跟踪约束让机位永远追脸、抹掉角色主动性。旋转、位移、变焦、对焦和速度分别写清；按 [相机执行](camera-cut-execution.md) 落实支持的通道。

动静对比是节奏手段：持续运动后的停顿可以强调发现，静止后的启动可以标记决定；不是每镜必须先停再动再停。环绕、甩摇、推拉变焦等手段仅在其改变的信息／体验确有必要时采用，并检验轴线、背景和遮挡。长镜头重视完整行动、信息转移和末端构图；不能靠一路找人来制造“电影感”。

时间先由表演、试读、感知和反应决定，再配合运镜。留观众读懂所需的窗口，不按固定秒数或均匀镜长分配。以原速度验证；不能用过度慢放、说明栏或抖动掩盖动作因果。

## 6. 参考、光色与风格要有明确用途

取参考时说明借用的是构图、明暗层次、光向／软硬、色彩关系、空间距离、运动节奏中的哪一项，以及它如何服务这场戏。一个参考不必控制所有维度；绘画和单帧能提示气氛，不能证明运动路径、接触或跨镜连续。静帧不得替代动态验证，照片颜色不得覆盖角色身份或已批准场景拓扑。

当任务包含 Lighting Previs／视觉风格时，组织前景／主体／背景的明暗、光源动机、软硬、色彩关系和人物进入／离开光区的变化。区分角色**识别色**与场景**情绪色调**，检查实际受光后身份是否仍可辨。亮暗、冷暖与类型片惯例是可选表达，不能推出“恐怖必暗、喜剧必亮、暖色必安全”。用当前剧情决定遵循或偏离惯例。

高调／低调不是简单增加／减少总曝光；判断亮暗分布和反差结构。光比数值若要记录，先明确测量对象与口径，不照抄示例数值作为所有场景阈值。照明计划必须检查切镜后是否仍有一致世界光源及人物受光关系，不能只把每个单镜打漂亮。

灰模任务只落实构图、层次、支撑和轮廓所需的照明。正式灯光仍走 [Lighting Context](lighting-context.md) 已有授权与测试；摄影学习不新增审批，也不自动增加写实灯光、调色或终片材质工作。

## 7. 以交付和实际样片检验导演意图

画幅从一开始影响同框、上下留白、空间和构图；不能在完成后为了审阅模板裁成16:9。提前知道目标播放尺寸、fps、画幅及下游用途，检查从 .blend 到编码视频的信息是否保留。书中胶片型号、早期数字设备、冲洗流程和成本判断属于历史语境，不作为当前 Blender 配置或采购建议。

对不确定的光影／运动／构图，用最短的有代表性片段测试：保持其事件前后和必要切点，而非仅交好看的定格。导演评价分别问：观众是否在预定时机获得信息？是否看见转折和反应？摄影是否帮助它发生？哪个实际画面支持这个结论？技术合格不等于情绪有效。

修正先找失败环节：剧情／信息设计 → 调度与遮挡 → 机位／镜头 → 时机／剪辑 → 光色／输出。按实际证据选择影响最小的授权改动，不必机械按顺序重做。反馈用“想让观众读到什么＋当前在哪个窗口读不到”比泛称“不够电影感”更可执行。沿用已有局部修改和候选预算。

书中“不把核心问题寄托给后期”的思想在这里转化为：Layout 中先解决关键站位、运动、镜头、节拍和因果；下游 AI 可以补外观／细节，不能被假定会自动修好缺失的动作关系。最终交接继续遵守具体版本定稿＋交付门禁；这份学习笔记不授予任何新的下游执行权限。
