# 本地案例提炼 · 2026-09-15—10-11

这些是适用边界明确的导演规则与执行经验，不是所有历史项目已经通过验收。项目证据索引保存在本次升级报告中，运行模块不引用这些项目绝对路径或坐标。

| 案例系列 | 问题与修正思路 | 通用沉淀与边界 |
|---|---|---|
| 匿名案例 01 | 横移拍成逐人瞄准；老师居中与烛台位置影响后续；1-33“特效”实际指特写；要求只渲染修改镜头 | 平移/瞄准/速度分离；当前字段授权优先；实质歧义一次确认；持续状态与全局照明依赖；不默认添加特效 |
| 匿名案例 02 | 文字本身连续摇移绕人；用户批准2-3在24秒内用正常切镜；要求仅平台 | 原表与新意图冲突要公开；明确子切点；简场服务调度；不给忠实版悄悄换结构 |
| 匿名案例 03 | 3-9换机位多轮仍失败，根因为人物背向关系；批准原地转向；去桌改地面进食；光照复用 | 先CAMERA/ACTION归因；不隐藏角色；动作授权不能扩大到其他镜头；变焦/升降如实标记；角色眼睫和睡姿细节仍受限 |
| 匿名案例 04 | 四狐关系和队列顺序、后续镜头没有继承；已导单镜不等于整场已更新 | 跨镜角色状态与镜头来源表；分镜表、实际导出和审阅状态分开 |
| 匿名案例 05 | 把未来站位前置；现实与回忆出口混淆；未经依据添加跪姿 | 看场前场后与时间层；方向来自真实场景和人物朝向；不从单帧批准推导完整路线批准 |
| 匿名案例 06 | 只改一个镜头，后续退回旧站位；世界中心≠画面中心；字幕跨一帧 | 状态持续到明确恢复点；相邻切点；统一帧表；局部复用须绑定真实来源 |
| 匿名案例 07 | 肩高平移被绕拍替代；炉火、锅体支撑与整件移动 | 相对眼/肩定义高度；稳定朝向；PROP/SCENE与Camera分账；不能只移动道具零件 |
| 匿名案例 08 | 斜线拉远夹杂中间转向/变焦；反应节拍不足 | 显式直线＋固定焦距/朝向；运动到位与反应停顿分别设计 |
| 匿名案例 09 | 威胁-察觉-应对因果；文字重建被用户否决 | 保留负例，不能从一次数值通过推导导演通过；文字原创需要可见因果而非复现坐标 |
| 匿名案例 10 | 最近顶点跳变误当滑动；抓持/支撑与越障恢复；代理root测距掩盖接触问题 | 稳定接触身份与扫掠轮廓；真实手物/支撑代理；复杂自然动作仍是LIMITED |
| 匿名案例 11 | root/COM过边不代表全身越过；旧测试和冻结数值保护 | 全身轮廓/支撑证据；新模块不能改旧期望；历史FAIL/LIMITED不因新测试通过变绿 |

PROJECT_FIX 保存项目参数；SKILL_FIX 只有脱离原场角色/镜号的实现与测试才晋级；DIRECTOR_RULE 记录适用条件；UNRESOLVED 保留不能稳定解决的限制。不要把项目制作成功直接当通用能力成功。
