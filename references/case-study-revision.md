# 匿名修改案例：由结尾反推依赖

修改已有 Layout 时，先识别导演要求的结果及受保护字段，再在版本副本上工作。

1. 对剪辑参考逐段区分删除、缩短、变速、重排、裁切与动作重写，保存源时间到目标时间的映射。
2. 先建立结尾必须成立的视线、距离和高低关系，再反推中段路线。由制作推导的站位应标为作者选择，不能冒充原分镜坐标。
3. 分组撤退必须遵守真实地形、遮挡和路线出口，保持镜外角色存在。路线图同时解释空间与时间。
4. 路线变化会连带影响摄影机、接触、支撑、道具和后续镜头。一次局部修改不能在下一镜退回旧状态。
5. 道具比例和字幕同步也要绑定同一版本。重导受影响镜头，复核相邻切点并重新组装整场。

本页为匿名经验提炼；原始素材、制作路径、私人对话和审批记录不公开。新任务须取得自己的实际证据。
