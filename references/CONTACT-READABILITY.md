# Contact response readability — measurable prerequisites

Optional `contact_readability` contract in CSP action_beats, with declared `contact_readability_state` on existing prop samples. States: APPROACHING, CONTACT_PENDING, CONTACT_ESTABLISHED, TRANSFER_ACTIVE, RESULT_VISIBLE, RECOVERY. These are observation windows, not inferred physics or a second timeline. Failed no-contact attempts explicitly mark established/transfer NA with reasons. Never fabricate contact/control to complete a sequence.

Owner: `contact_readability.attach/evaluate`; native read-only measurement: `contact_readability_native.measure`. Reuses S3 evaluated mesh projection and estimated camera-ray occlusion. Requires matching existing S003 cause/result IDs, actor/prop identity, native contact-point gap, native controller outcome, fixed windows, response direction and authored threshold provenance. Apply before normal CSP Builder; no Builder awareness of the new capability is required. Use `combat_sequence_package.validate` to validate the optional contract.

The evaluator requires legible actor/prop/contact witnesses, a consecutive visible causal interval, visible result motion and evidence for each applicable phase including recovery. World response direction is separate from screen displacement; moving Camera cannot prove World response. Only visible screen samples contribute result displacement. Projected bounds are not visible pixel masks; ray occlusion is ESTIMATED.

Diagnostics: CONTACT_NOT_VISIBLE, RESPONSE_WITHOUT_VISIBLE_CAUSE, CAUSE_WITHOUT_RESULT, WRONG_CONTACT_DIRECTION, CONTACT_PHASE_SKIPPED. Missing evidence is NOT_REVIEWED. Known offscreen subjects are a visibility failure, not missing ray evidence. A FAIL never changes motion, Camera or director intent.

Initial limits are explicit TECHNICAL_DEFAULT for 480x270 30fps proxy testing (0.12H actor, 0.06H prop, 0.003H contact witness, 0.8 projected visible fraction, 0.5 unoccluded ray fraction, 6 consecutive frames, 0.015 screen displacement). Short authored transition phases require all their available frames. No universal human perception threshold is claimed. See contract DEFAULTS and each report for exact values.

PASS only certifies these measurable prerequisites. Small unconnected control markers, absent arms, crude poses or poor causality can still be visually ambiguous to a person. Human director review remains PENDING_DIRECTOR_REVIEW. This module does not create IK, fingers, skeletons, collision, dynamics, Camera strategy, combat contact, takeoff or landing. Prototype framing is explicitly authored test data, never an automatic Camera Director. Parent/rotating handle coordinates must use the existing S003 supported contact representation; general handle transforms are not newly supported.
