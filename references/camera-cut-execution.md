# 摄影与切镜执行

摄影不是移动量比赛。先用“本镜信息如何从起幅到落幅发生变化”选择手段，再填写参数。场景米制、角色眼高、感光面、实际画幅和 lens_mm 一起决定构图，焦距数字本身不等于景别。

设计或诊断时读 [摄影决策方法](cinematography-for-layout.md)：机位距离决定观察关系，焦距与有效感光面共同决定视角；同机位变焦不等于推轨产生的透视／视差变化。景深与焦点用于分配信息，不默认浅景深。先看同框调度与剪辑是否足够，再选择有动机的运动与动静节奏；不因某种手法被书籍采用就强制套用。此指南没有增加变焦、跟焦或复杂 rig 的自动执行能力。

| 意图 | 几何执行 | 审查重点 |
|---|---|---|
| 固定 | STATIC_HOLD，位置和朝向固定 | evaluated position、quaternion、焦距均稳定 |
| 固定机位摇／俯仰 | STATIC_ROTATION，世界位置不变 | 旋转方向、角速度、揭示内容；不能加漂移求平滑 |
| 推拉／横移 | STRAIGHT_TRANSLATION，单一标量控制世界直线 | 相对画面方向、起落幅、速度与停顿；朝向可固定，不自动追踪每个人 |
| 直线跟拍 | STRAIGHT_TRACKING，路径直线，显式瞄准 | 主体相对位移；不把看向主体变成绕行 |
| 升降 | VERTICAL_CRANE，XY不变 | 上摇与升降不同；需要变焦必须独立说明 |
| 有目的的环绕／弧线 | ORBIT / INTENTIONAL_ARC | 轴线、遮挡窗口、半径和方位变化目的；技术结果仍需意图审查 |
| 多阶段 | COMPOUND_MOVE，显式分段、连续端点 | 只有明确需要才使用；不拿它自动串联所有人物 |
| 切镜 | 每镜独立摄影机 + 起帧 Camera Marker | 前一镜末帧与下一镜首帧实际生效摄影机，不允许镜间飞行 |

直线位置 P(t)=A+s(t)(B−A)，共享 s(t)；时间缓动不改变空间路径。不要对 XYZ 分别设不一致的缓动。控制器坐标不等于实际摄影机：检查 evaluated Camera World Matrix，包括父级、约束和驱动影响。正式 1.8 相机适配器只创建无父级新镜头；原复杂 rig 不强行烘焙或清除约束。

旋转、瞄准也有叙事节拍：谁先被看见、何时交接注意力、落幅多久可读。快速拉到位再极慢后拉，应记录两个速度段；不能每个节点都零速导致机械停走。轨迹平滑不代表可读，速度曲线好看也不证明构图正确。

跨镜检查主轴、屏幕左右、视线目标、走向与动作相位。合法越轴需交代空间或明确意图，不能仅按符号一律判错。多人落幅必须结合人物动作和遮挡看视频。身体朝向、视线与世界坐标不同；代理局部前方先实测。

保留原镜号和时间段；经批准的镜内硬切采用父镜号子镜段与明确切点，不能伪称单一连续运镜。保守版和 DIRECTOR_ALTERNATIVE 分开保存。时间区间新接口为 [start,end)，Blender frame_end 和旧 QA 是闭区间；显式减一转换，字幕与切点统一从同一帧表生成。
