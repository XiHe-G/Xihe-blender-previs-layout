# Contact witness calibration — EXPERIMENTAL

Use only for an explicitly authorized isolated study, not production camera selection. `witness_calibration_native.run(spec, output)` reads a frozen accepted CSP/Blend, records source hashes, uses a prescribed fixed Camera, and permits declared observation-only witness geometry, occluders, body-facing variants and witness exposure. It never writes to the source scene or selects a winning view. Reuses the unchanged S006 measurement/validator.

World route, timing, native control/support metadata and motion consequences remain fixed. Original world matrices must compare exactly after save/reopen except explicitly declared body-yaw presentation channels. Source cameras remain present/unmodified; a separate calibration camera observes the timeline. Simple connectors/contours are not anatomical arms, IK, collision or new animation skill. Witness exposure changes visibility only, not contact duration or hold in the motion itself.

Direction must come from an accepted momentum response target or a named accepted CSP result path. Path tangent is not a force estimate. Missing/zero/nonfinite direction is NOT_REVIEWED. Never use an unconditional +X default. Camera FRONT/REAR labels in this first harness are relative to that resolved movement axis, not inferred actor gaze.

Record motion/contact/direction/camera/threshold/review provenance separately. OFAT author parameters do not guarantee all measured screen properties are independent: angle also changes apparent scale and overlap. Keep actual measurements and avoid causal overclaims. Reused motion and duplicate stimulus trials are not independent new behavior evidence.

`calibration_diagnostics` provides experimental annotations only: body/contact disconnection, overly abstract point witness, projected axis compression and long causal separation. They are not global gates. A mechanical PASS only proposes a measured configuration for human review; no artistic or human-recognition score is generated.

Blind packet: neutral variant IDs, clean videos, R1–R5 PASS/FAIL/UNCERTAIN answers and free interpretation. Store the experiment key outside that packet; do not show technical expectations first. `review_template` must remain pending until actual independent responses arrive. `validate_review` records answers but never promotes capabilities automatically.

Readability envelope is an enumerated set of tested mechanically readable candidates, conditioned on proxy, resolution, frame rate and geometry. It is not a universal rule or an automatic Camera Director. Same-validator pass/fail cannot calibrate its own perceptual thresholds. Without independent human evidence, threshold audit is INSUFFICIENT_EVIDENCE; keep existing defaults for compatibility without calling them perceptually validated. S006 remains EXPERIMENTAL.
